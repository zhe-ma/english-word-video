# 荧光笔手帐

本地生产竖屏中英混读单词短视频。文案和判断可以交给 Cursor Agent，选词、校验、配音、渲染、管理都在本机完成。

```bash
./scripts/setup.sh          # 首次安装
./vv serve                  # 打开工作台 http://localhost:5173
```
